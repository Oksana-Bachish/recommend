# Асинхронный микросервис рекомендаций (FastAPI)

Высокопроизводительный изолированный микросервис на базе FastAPI, разработанный для генерации рекомендаций товаров. 
Сервис асинхронно извлекает данные из базы данных PostgreSQL на основе фильтрации категорий и ЧПУ-слагов.

## 🔧 Функциональность

- **Асинхронная архитектура**: Построен на FastAPI и `asyncio` для обработки неблокирующих операций ввода-вывода (I/O).
- **Оптимальное подключение к БД**: Реализует асинхронный пул соединений через библиотеку `asyncpg`.
- **Контейнеризация**: Полностью упакован в Docker и поддерживает как изолированный локальный запуск, 
так и деплой в продакшен.


## 🛠️ Стек технологий

- **Язык разработки**: Python 3.10
- **Веб-фреймворк**: FastAPI
- **Драйвер базы данных**: Asyncpg (PostgreSQL connection pool)
- **Валидация данных**: Pydantic v2
- **Инфраструктура**: Docker / Docker Compose

## 💻 Локальный запуск и разработка

Для развертывания и тестирования микросервиса в изолированном локальном окружении выполните следующие шаги:

1. Выберите папку, куда будете клонировать Git-репозиторий:
```bash
cd <имя_папки>
```

2. Клонируйте репозиторий:
```bash
git clone https://github.com/Oksana-Bachish/recommend.git
```

3. Перейдите в директорию проекта:
```bash
cd recommend
```

4. Создайте файл `.env.dev` в корневой директории проекта:
```env
POSTGRES_DB=your_db_name
POSTGRES_USER=your_db_user
POSTGRES_PASSWORD=your_db_password
POSTGRES_PORT=5432
POSTGRES_HOST=127.0.0.1
ALLOWED_ORIGINS=http://127.0.0.1:8000,http://localhost:8000
```

5. Убедитесь, что установлен Docker:
```bash
docker --version
```

6. Запустите мультиконтейнерную архитектуру (FastAPI + локальная БД) командой:
```bash
docker compose up -d --build
```

7. Проект покрыт интеграционными тестами с использованием `pytest` и `httpx.AsyncClient`. Для запуска тестов выполните:
```bash
docker compose exec fastapi_recommend python -m pytest
```

После запуска Swagger-документация API будет доступна по адресу: `http://127.0.0.1:8085/docs`

## 🐳 Развертывание на сервере (Production)

На сервере (`CloudVPS`) микросервис подключается напрямую к базе данных через изолированную внешнюю
сеть Docker (`backend_app_net`). Это позволяет не открывать порты базы данных в публичный
интернет.
